# Image skills

| Skill | Output |
| --- | --- |
| [Field Note Illustrations](field-note-illustrations/SKILL.md) | Twenty handmade styles as separate transparent, theme-matched illustrations. |
| [Photo Editorial Poster](photo-editorial-poster/SKILL.md) | One 3:4 poster per photo, with an exact 50/50 photo-and-illustration split. |
| [Rubber Stamp Travel Notes](rubber-stamp-travel-notes/SKILL.md) | One 4:3 poster per photo, with a 58/42 photo-and-stamp layout. |

Use **Field Note Illustrations** for website artwork without a photo panel, frame, or background rectangle.
Use the poster skills only when the user requests those layouts.

Each skill is self-contained. Read its `SKILL.md` first.
The field-note library includes numbered style folders, reusable prompts, transparent examples, source credits, and a visual index.
Its preparation script requires Python 3, Pillow, and NumPy. Image generation requires a separate image tool.

The website gallery is at `/illustrations/` in `packages/nz`.
See [artwork provenance](../../packages/nz/src/assets/queenstown-artwork.md) for the source photograph and generated assets.
