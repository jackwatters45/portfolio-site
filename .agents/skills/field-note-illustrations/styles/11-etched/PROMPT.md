# 11 · Etched

Fine drypoint contours with selective crosshatching and slight ink burr.
This is sharper than Pencil and less repetitive than Contour study.

Read the [shared prompt](../../references/prompts.md). Add the actual scene and palette, then this style block.

## Style prompt

```text
Interpret the reference as a delicate drypoint or etched print.
Use one muted primary ink with an optional tiny earthy accent.
Preserve the distinctive silhouette and the positions of the important forms.

Use fine, slightly irregular incised lines.
Add sparse parallel hatching and short crosshatched patches to describe only the important shadows.
Allow slight fuzzy ink burr along a few lines, as in a lightly inked drypoint impression.

Keep most of the image open.
Let secondary details stop early or disappear into empty space.
Do not cover every slope, surface, or object with hatching.

Avoid a plate border, paper rectangle, technical diagram, map labels, or dense antique engraving.
The lines must remain readable at the intended website size.
Do not simulate the style by applying a uniform photo-edge filter.
```

## Preparation and checks

- Start with cutoff `0.065`; try `0.045` if essential thin lines disappear.
- Retain the slight burr without retaining background haze.
- Check small crosshatched areas at page size. They must not become solid dark patches.
- Keep lines more incised and deliberate than Pencil's grainy, doubled strokes.
