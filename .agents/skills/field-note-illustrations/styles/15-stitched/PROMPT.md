# 15 · Stitched

Broken running stitches with a few thread-filled patches.
This uses visible stitch rhythm, not an ordinary dashed vector outline.

Read the [shared prompt](../../references/prompts.md). Add the actual scene and palette, then this style block.

## Style prompt

```text
Make an illustration of the reference using the appearance of hand embroidery.
Use one muted thread color and a very small second-color accent.
Retain the main silhouette and the positions of important forms.

Describe contours with uneven running stitches and occasional longer thread marks.
Vary the stitch length, spacing, and direction slightly.
Fill only a few small dark forms with closely placed stitches.
Let the thread show subtle twisted fibers within the marks.

Keep most of the scene as open space.
Use stitch direction to suggest slopes, vegetation, or other useful forms without drawing every detail.
Keep the image flat enough to function as a website illustration.

Do not include fabric, a hoop, needles, loose tools, a cloth rectangle, or cast shadows.
Avoid a photographic embroidery mockup and dense stitching across the whole canvas.
```

## Preparation and checks

- Start with cutoff `0.065`; lower it only if fine thread marks disappear.
- Keep the gaps between stitches transparent.
- Retain fiber detail inside the thread, not a woven fabric texture behind it.
- At page size, confirm that stitch spacing remains visible and filled patches do not become solid blocks.
