# 16 · Contour study

Nested lines follow the visible forms in perspective.
These are artistic contours, not measured elevations or survey data.

Read the [shared prompt](../../references/prompts.md). Add the actual scene and palette, then this style block.

## Style prompt

```text
Interpret the reference as a light, hand-drawn contour study.
Use one muted primary ink, with no filled color areas.
Keep the source viewpoint, the main silhouettes, and the relative positions of the forms.

Draw nested, flowing lines that follow the apparent shape of each visible surface.
Vary spacing and line weight slightly.
Use open, incomplete passages where detail is not needed.
Allow a few lines to wander or break, as in an observational drawing.

Keep the important empty spaces clear.
Do not fill the sky, open water, or every gap with decorative lines.
Avoid dense uniform hatching and mechanically repeated offsets.

These contours are artistic descriptions of visible forms, not surveyed elevation lines.
Do not add a coordinate grid, altitude numbers, labels, a scale bar, or a claim of geographic accuracy.
```

## Preparation and checks

- Start with cutoff `0.065`; try `0.045` if delicate lines disappear.
- Use one primary pigment unless the user's palette requires another.
- Keep adjacent contour lines separate at page size. Regenerate with wider spacing if necessary.
- Describe the result as an artistic study, never as a navigation or terrain dataset.
