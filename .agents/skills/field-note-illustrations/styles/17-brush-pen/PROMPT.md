# 17 · Brush pen

Spare tapered strokes with clear pressure changes.
These are narrower and more contour-led than Dry brush's broad painted sweeps.

Read the [shared prompt](../../references/prompts.md). Add the actual scene and palette, then this style block.

## Style prompt

```text
Draw the reference with a flexible brush pen in a few confident gestures.
Use one dark primary ink and, if useful, one tiny earthy accent.
Retain the distinctive silhouette and essential spatial relationships.

Make each stroke change width with the pressure of the brush tip.
Use sharp tapered ends, occasional dry-tip breaks, and a few heavier turns.
Let one stroke describe a long contour instead of using many short repeated marks.

Keep almost all interior areas empty.
Use only a few short dark accents to suggest depth or important objects.
Allow contours to stop and resume rather than closing every shape.

Avoid solid painted masses, broad roller marks, crosshatching, decorative lettering, and uniform vector strokes.
The result should feel spare and deliberate while remaining recognizable at small website sizes.
```

## Preparation and checks

- Start with cutoff `0.065`. Use a second pigment pair only when an accent exists.
- Keep tapered ends intact. Lower the cutoff slightly only if they disappear.
- Check pressure changes at page size. Do not replace them with uniform thick outlines.
- Keep enough contour breaks to distinguish this from a smooth vector tracing.
